## О проекте

QSKeyboard - экранная клавиатура для X11, которая появляется жестом на сенсорном экране. Поддерживаемые платформы: Linux, FreeBSD. 

## Возможности

**Показ и скрытие**
 - Показ: два быстрых касания двумя пальцами по сенсорному экрану
 - Скрытие: касание или клик вне клавиатуры, либо переход фокуса ввода в другое окно

**Клавиша !AT (Alt+Tab)**
 - Alt остаётся зажатым 3 с после последнего нажатия (каждое нажатие нажимает Tab и перезапускает отсчёт 3 с)
 - Alt отпускается по таймауту, по любой другой клавише, при скрытии клавиатуры и при выходе из программы

**Клавиша !HK (горячие клавиши)**
 - Переключает на раскладку горячих клавиш: одна кнопка на строку файла `~/.config/QSKeyboard/hotkey.conf` (создаётся при первом запуске)
 - 5 рядов по 6 слотов, последний слот - `ABC`
 - Нажатие кнопки эмулирует комбинацию и скрывает клавиатуру, `ABC` возвращает буквы

**Клавиша Close**
 - Завершает программу

Формат `~/.config/QSKeyboard/hotkey.conf`: одна комбинация на строку, клавиши через `+`, `#` начинает комментарий, используется до 29 строк.

Модификаторы: `ctrl`, `alt`, `shift`, `super`. Остальные клавиши - имена keysym X11.

## Сборка / Запуск

**FreeBSD**

```
doas pkg install gtk3 libXi libXtst libX11 pkgconf

make
./QSKeyboard
```

**Ubuntu / Debian**

```
sudo apt install build-essential pkg-config libgtk-3-dev libxi-dev libxtst-dev libx11-dev

make
./QSKeyboard
```

## Технологии

 - C, GTK3, XInput2, XTest, Xlib
